# 버벌진트, 음주운전을 말한 가사들 2016–2026

버벌진트가 2016년 음주운전 적발 이후 발표한 곡 가운데, 가사에서 음주운전을 언급한 대목을 모은 인터랙티브 그래프입니다. 옵시디언 그래프 뷰처럼 곡을 노드로, 언급 대목을 그 노드에 매달린 메모로 표현했습니다.

- 곡은 발매 순서대로 왼쪽(2016)에서 오른쪽(2026)으로 배치됩니다.
- 대목에 마우스를 올리면 크게 표시되고 곡 제목·앨범·발매일이 함께 나옵니다.
- 클릭하면 해당 곡의 유튜브 영상으로 이동합니다.
- 글자벽 보기(`wall.html`): 모든 대목을 화면 가득 채운 타이포그래피 벽. 그래프 화면의 「글자벽」 버튼으로 이동합니다.
- 「가사 입력 모드」에서 각 대목에 가사를 직접 입력할 수 있습니다. 입력 내용은 보는 사람의 브라우저(localStorage)에만 저장됩니다.

## 조사 범위

멜론에 등록된 2016년 1월부터 2026년 11월까지의 본인 명의 곡과 피처링·참여곡 가사를 키워드로 검사한 뒤 문맥을 읽고 판정했습니다. 노드의 기본 문구는 가사 원문이 아니라 해당 대목의 요지입니다.

## 실행

`index.html` 하나로 동작합니다. GitHub Pages로 배포됩니다.
